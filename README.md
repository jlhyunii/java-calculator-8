# java-calculator-precourse

#### 문자열로 전달된 숫자를 구분자 기준으로 분리하여 합산하는 문자열 계산기 프로그램
<br>

### 1. 입력 및 출력 기능
- 사용자로부터 문자열 입력을 받는다.
  - `camp.nextstep.edu.missionutils.Console`의 `readLine()` 사용
  - 입력 전 `덧셈할 문자열을 입력해 주세요.`를 출력
- 결과를 `결과 : X` 형식으로 출력한다.

### 2. 기본 구분자(쉼표`,`, 콜론`:`) 처리
- 입력값이 비어 있는 경우 0을 반환한다.
- 기본 기본자를 기준으로 숫자를 분리하고 합산한다.
  - 예: `1,2:3` -> `6`

### 3. 커스텀 구분자 처리
- 입력값의 형식이 `//[구분자]\n[문자열]`인 경우, 지정된 커스텀 구분자를 사용한다.
  - 예: `//;\n1;2;3` -> 구분자 `;` 기준으로 합산 -> `6`

### 4. 유효하지 않은 입력 예외 처리
- 4-1) 음수가 포함된 경우 예외 발생
  - 예: `1,-2,3`
- 4-2) 숫자가 아닌 문자가 포함된 경우 예외 발생
  - 예: `1,a,3`
- 4-3) 잘못된 커스텀 구분자 포맷인 경우 예외 발생
  - 예: `//;1;2`

### 5. 기타 유효성 검사
- 연속된 구분자 또는 빈 토큰이 존재할 경우 예외 발생
  - 예: `1,,2`
- 구분자 이외의 특수문자가 포함된 경우 예외 발생
  - 예: `1,2#3`
